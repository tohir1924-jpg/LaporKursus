Saya ingin kamu membangun UI/UX web app bernama **LaporKursus**.

Aplikasi ini adalah web app manajemen kursus untuk mengelola:

* data siswa
* kelas/program kursus
* absensi kehadiran
* SPP bulanan
* pesan pengingat WhatsApp
* laporan project siswa
* profil siswa
* laporan umum

Gunakan stack frontend:

* React
* Tailwind CSS
* lucide-react untuk icon
* komponen reusable
* dummy data lokal dulu
* belum perlu integrasi backend
* UI harus siap dikembangkan nanti untuk Cloudflare Pages + D1

Fokus utama tugas ini adalah membuat **UI/UX desktop web app yang sangat polished**, bukan backend.

# Target Visual

Buat desain dengan gaya:

* modern SaaS dashboard
* clean
* profesional
* ringan
* ramah untuk lembaga kursus
* light theme
* banyak white space
* rounded cards
* soft shadow
* border tipis
* warna biru, teal, hijau lembut
* tidak terlalu ramai
* tidak dark mode
* tidak terlihat seperti template admin jadul

Gunakan kesan visual seperti aplikasi manajemen pendidikan yang premium, rapi, dan mudah dipakai.
